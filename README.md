# sistema reservas

Proyecto de desarrollo de un sistema de reservas para un restaurante, he utilizado Spring Boot, Thymeleaf y Bootstrap

## Tech Stack

Java, Spring Boot, Thymeleaf and Bootstrap

## Getting Started

```bash
git clone https://github.com/MagdaIG/sistema-reservas.git
cd sistema-reservas
./mvnw spring-boot:run
```
